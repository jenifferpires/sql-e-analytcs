# 📂 Camada de Dados (Raw Data).  

Esta pasta contém amostras (samples) dos dados brutos para validação do pipeline.

## 📋 Arquivos de Amostra:
1. **clientes.csv**: IDs e pontos acumulados.
2. **produtos.csv**: Catálogo de itens (RPG, armas, etc).
3. **transacoes.csv**: Registro das vendas (Fato Principal) - Conecta clientes ao evento de compra.
4. **transacao_produto.csv**: Detalhamento dos itens contidos em cada transação.

> ⚠️ **Atenção:** Para processar o volume real de +300 mil registros, baixe o dataset completo no link abaixo.

## 🔗 Fonte dos Dados:
Dataset original: [TeomeWhy Loyalty System - Kaggle](https://www.kaggle.com/datasets/teomewhy/teomewhy-loyalty-system).
