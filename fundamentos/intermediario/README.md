# 📘 Módulo Intermediário — SQL e Analytics.

Este módulo marca a transição do **SQL fundamental** para o **SQL analítico intermediário**, introduzindo conceitos essenciais para consultas mais complexas, relacionamentos entre tabelas e análises estruturadas. 

Aqui você aprenderá **como os dados se relacionam**, **como quebrar problemas complexos em partes menores** e **como escrever consultas mais legíveis e poderosas**.

---

## 🎯 Objetivo do Módulo: 

Ao concluir o módulo **Intermediário**, você será capaz de:

* Combinar dados de múltiplas tabelas usando `JOIN`
* Utilizar **subqueries** para resolver problemas em etapas
* Aplicar **CTEs (Common Table Expressions)** para organizar consultas complexas
* Evoluir de consultas lineares para raciocínio analítico em SQL
